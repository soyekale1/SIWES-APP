\# SIWES-APP



\## Project Overview

SIWES-APP is a project developed as part of my Student Industrial Work Experience Scheme (SIWES) training. The purpose of this application is to demonstrate practical software development, cloud, and DevOps concepts.



\## Features

\- Application deployment support

\- Cloud-ready architecture

\- Version control with Git and GitHub

\- Beginner-friendly project structure



\## Technologies Used

\- Python

\- Git

\- GitHub

\- Docker

\- AWS Cloud

\## Installation

Clone the repository:



```bash

git clone https://github.com/soyekale1/SIWES-APP.git

```



Move into project directory:



```bash

cd SIWES-APP

```



Run the application:



```bash

python app.py

```
